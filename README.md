MatchLab helps students find scientific and practical projects, join teams, and build a portfolio of confirmed contributions. Project initiators can publish ideas and recruit people for specific roles.

This guide covers the Android application. The initial interface is in Russian; action names below describe their purpose and may differ slightly from the labels in your installed release.

## Install and update the application

### Before you start

You need an Android device compatible with the selected release, an internet connection, and access to an academic email address accepted by MatchLab. Check the release notes for the supported Android version and any installation requirements.

### Install the APK

1. Open the official [MatchLab Android releases page](https://github.com/HSE-Scientists-Team/Mobile-App/releases).
2. Select the Android release you want to install and read its release notes.
3. Under **Assets**, download the `.apk` file. The source-code ZIP and TAR archives are not installable applications.
4. Open the downloaded APK from your browser's downloads or the Android file manager.
5. If Android requests permission, allow the browser or file manager to install this application using the setting shown by the system.
6. Select **Install**, wait for installation to finish, and open **MatchLab**.

### Update an existing installation

Download the newer APK from the same official release page and install it over the existing application. Follow any update instructions in the release notes. Do not uninstall the existing app as a routine update step, because uninstalling can remove local application data.

If Android reports a signature conflict or refuses the update, check that you downloaded the correct APK and consult the project's release notes before removing the existing installation.

## Register and sign in

### Create an account

1. Open MatchLab and select the registration option.
2. Enter your academic email address and the account information requested by the form, including your password.
3. Submit the form. If a field is invalid, correct the message shown beside it.
4. Open your academic mailbox and find the confirmation email.
5. Follow the confirmation link and complete the confirmation action on the page or in the application.
6. Return to MatchLab and sign in.

Registration requires an email domain accepted by the platform. Confirming ownership of your email activates your registration; it does not verify your entire profile or portfolio.

Enter your registered email address and password. If your session expires, sign in again. To end your session, use the sign-out action in the account settings.

## Complete your profile

1. Open **Profile** and select the edit action.
2. Add your display name and a short introduction.
3. Enter your skills, interests, preferred roles, and availability where the form supports them.
4. Add education and portfolio items. Describe your own contribution and attach relevant links or supporting materials.
5. Save your changes and review the profile.

Complete the required profile fields before publishing a project, applying to a role, or accepting an invitation. Verification of portfolio items is optional for these actions.

## Find projects and people

1. Open **Feed** and choose projects or people.
2. Enter a search query or open the filters.
3. For projects, narrow the results using the available type, domain, skills, dates, and open-role filters.
4. Open a project to review its problem, goal, expected workload, dates, initiator, team, and available roles.
5. Open a participant's profile to review their visible skills, experience, and feedback.

If the search returns no results, remove restrictive filters or try a broader query. Recommendations help you discover opportunities; they do not submit applications or join teams for you.

## Apply to a project or accept an invitation

### Apply to an open role

1. Open a project that is recruiting participants.
2. Select an available role and review its requirements.
3. Select the application action and add a short message explaining your fit and availability.
4. Submit the application.
5. Open **Applications** to follow the decision. You can withdraw an application while it is pending.

Submitting an application does not create membership. You join the team when the initiator accepts it and a position is still available.

### Respond to an invitation

1. Open **Applications** and switch to received invitations.
2. Review the project, proposed role, and initiator's profile.
3. Accept or decline the invitation.
4. After acceptance, check that the project appears in your participant projects and that your role is correct.

If the role has already filled, refresh the project and review other openings. Avoid resubmitting the same action before checking its current status.

## Create a project and recruit a team

### Publish a project

1. Open **Projects** and select the create-project action.
2. Enter the title, type, domain, problem, goal, dates, expected workload, and relevant tags.
3. Add at least one open role. Specify its responsibilities, required skills, and number of positions.
4. Review the information and publish the project.
5. Correct any missing or invalid fields identified by the form.

### Manage recruitment

1. Open the project from the list of projects you initiate.
2. Review applications grouped by role and inspect the candidates' profiles.
3. Accept or reject applications, or invite a suitable person to a specific open role.
4. Check the team and remaining positions after each decision.
5. Update role information when necessary. Existing memberships must remain valid.

You can revoke a pending invitation. Where available, unpublishing stops new recruitment while preserving the project's existing history.

## Communicate with other participants

Open a participant's profile and use the chat action, or select an existing conversation in **Chats**. Review the recipient before sending a message.

**Release availability:** the mobile README currently describes chats as local-only, while the backend documents a Chat service. Check the installed release notes before relying on message delivery. A local-only conversation does not send messages to the other participant.

## Complete a project and confirm your contribution

### For the initiator

1. Open the project's management screen.
2. Start the recruiting project when the team is ready. Starting requires at least one accepted member.
3. When the work is finished, choose the completion action.
4. Record the overall result and indicate the members whose contributions are complete.
5. Review the consequences and confirm completion.

### For a participant

1. Open the completed project and review the contribution attributed to you.
2. Confirm the contribution if it is accurate, or dispute it if it is not.
3. Check the resulting project-linked portfolio record and its confirmation status.

Project completion and individual contribution confirmation are separate actions. Cancelled projects and unconfirmed or disputed work do not become verified completed work automatically.

## Leave a review

1. Open the profile of a person with whom you have eligible confirmed participation in the same project.
2. Select the review action and the relevant project, if prompted.
3. Choose a rating from 1 to 5 and write a comment about the collaboration.
4. Submit the review.

You cannot review yourself or submit multiple reviews of the same person for the same project. If the action is unavailable, check the project and contribution confirmation states.

## Verify portfolio and education items

1. Open the relevant item in your profile.
2. Submit a verification request with the evidence required for that item.
3. Follow its status: not submitted, pending, additional information required, approved, or rejected.
4. If additional information is requested or the request is rejected, read the explanation, update the evidence, and resubmit where available.

Verification applies to the selected item. Editing a verified claim or replacing its evidence requires a new review. You can collaborate without verified portfolio items if your account is active, unrestricted, and has the required profile information.


## Privacy, blocking and reports

### Manage privacy

Open the account settings and review the available visibility options. Only publish information you intend other participants to see. Raw verification evidence and private messages are separate from public profile information.

### Block or report

- To stop unwanted contact, open the user's available actions and choose the block action. Manage blocked users in settings.
- To report a user or project, open its report action, select a reason, describe the issue, and add relevant evidence where supported.
- Keep the confirmation or case reference after submission. Reporting and blocking are separate actions.

If you leave a project, review the confirmation dialog before proceeding. Leaving preserves participation history but does not confirm completed work.

## Troubleshooting

| Problem | What to do |
| --- | --- |
| The APK will not install | Check the supported Android version and release notes. Confirm that you downloaded an APK rather than a source archive. |
| An update fails | Check the selected release and application signature. Follow the release instructions before uninstalling anything. |
| Registration rejects my email | Check the address and whether its academic domain is accepted. |
| The confirmation email has not arrived | Check spam and the entered address. If a resend action is available, request a new email and use the latest confirmation link. |
| A confirmation link is invalid or expired | Request a new confirmation email using the available registration flow. |
| I cannot apply, publish, or accept an invitation | Confirm your email, complete the required profile fields, and check the project status and remaining positions. |
| Search returns no results | Remove filters or broaden the query. |
| An acceptance reports a conflict | Refresh the application and team status. Another acceptance may have filled the last position. |
| A request fails after a connection loss | Restore the connection and check the current state before repeating the action. |
| Messages do not reach another user | Check whether the installed release supports server-connected chat. Local-only chat does not deliver messages. |
| I cannot leave a review | Check that both users have eligible confirmed participation in the same project and that you have not already reviewed that person for it. |

For release instructions and project updates, visit the [official mobile repository](https://github.com/HSE-Scientists-Team/Mobile-App) or the [Scientists team on GitHub](https://github.com/HSE-Scientists-Team).
